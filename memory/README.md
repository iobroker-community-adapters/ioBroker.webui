# Project memory

This directory is the durable, repository-scoped memory for `ioBroker.webui`. Future Codex sessions should read these notes before changing the project and update them when a material decision or constraint changes.

## Files

- `project-overview.md` — stable project structure, build behavior, and recurring constraints.
- `dependency-upgrade-2026-08.md` — decisions and compatibility findings from the August 2026 dependency upgrade.
- `verification.md` — useful verification commands and known test-environment behavior.

## Maintenance rules

- Record verified, reusable project knowledge—not a transcript of a task.
- Date facts that can become stale and link them to repository files where useful.
- Amend stale information rather than accumulating conflicting entries.
- Never store secrets, credentials, personal data, hidden reasoning, or raw logs here.
